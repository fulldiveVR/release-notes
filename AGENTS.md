# AGENTS.md

This repository publishes public release notes for FullDive products.

- Keep notes user-facing. Do not publish private repository URLs, issue IDs, commit hashes, infrastructure details, customer data, secrets, or unreleased work.
- Store one release in each `_releases/<product>/<date>-<slug>.md` file.
- Keep product metadata in `_data/products.yml`.
- Run `python3 scripts/validate.py` before committing.
- Treat generated `_site/` output as disposable. Do not commit it.
