- Simplified navigation across chats, rooms, agents, threads, and unread activity, with improved mobile behavior and thread navigation.
- Added refreshed onboarding content and layouts for small screens, with clearer guidance for reaching the Assistant and updated localized copy.
- Added interactive mini-app and event support, richer HTML previews and dashboards, improved media fallback messaging, and an option to request unavailable files.
- Improved agent workflows with room message reply actions, thread agent suggestions, room-wide mentions for eligible users, clearer job-run status, and more consistent agent layouts.
- Meeting reports now include links to their recordings, while voice interactions better handle interruptions, long responses, greetings, and conversational context.
- Polished message previews, context-menu behavior, search access, headers, branding, and other responsive layout details.
