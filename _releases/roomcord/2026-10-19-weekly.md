- Improved link and mention contrast across appearance themes for clearer reading.
- Server selection now respects the server specified by invite and shared links, including links to the default server.
- Rooms show live agent activity, with a streamlined room and settings experience.
- Paired computers are easier to manage from My Agents, with clearer status, direct messaging, and revoke actions.
- Calls now avoid repeating spoken answers, while microphone processing and caption display have been refined.
- Browser assistance is more reliable, with improved viewer startup, mobile zoom and panning, clearer errors, and working cancellation.
