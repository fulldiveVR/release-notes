- Added image markup tools for received images, including drawing, shapes, arrows, text, cropping, undo, and clear actions. Edited images can be staged as new attachments, with localized guidance and clearer handling for unsupported formats.
- Refreshed chat message styling, restored agent avatars, and improved unread indicators so messages are easier to scan and read status stays accurate.
- Improved voice-agent behavior so agents remain in a listening state, can be interrupted more reliably, and avoid treating background noise or their own audio as a person speaking.
- Improved scheduled activity delivery and status reporting, including more accurate next-run information and better handling for personal conversations.
- Fixed image saving on mobile devices so saved images are written to the device photo library with clearer permission and failure messages.
- Polished desktop layout, footer sizing, thread scrolling, navigation visibility, and thread opening behavior for a more consistent interface.
