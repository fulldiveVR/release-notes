- Meetings now start in the active conversation, with clearer contextual controls and improved meeting reports and transcripts.
- iPad uses a desktop-style layout, while foldable iPhone screens receive posture-aware layouts that keep actions and headers accessible.
- Mobile users can explore browser screen graphs with expanded details and simpler navigation.
- Audio attachments use a more compact, seekable player that replays cleanly and continues playback through routine message updates.
- Calls support selecting external cameras and recover an active microphone when its device temporarily disconnects.
- Room navigation, thread sharing, file actions, search, onboarding, and agent messaging have been refined for a smoother workflow.
