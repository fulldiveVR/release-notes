- Thread previews now show summaries, agent suggestions, unread activity, and correctly formatted quoted replies.
- Added adaptive room search and a keyboard shortcut for searching direct chats.
- Unavailable media cards now explain what is missing instead of loading indefinitely, with an option to request the file from the agent when available.
- Scheduled jobs provide clearer delivery status, output counts, run details, and navigation to the room where results are posted.
- Agent progress updates and voice interactions are more reliable, with clearer localized status messaging.
