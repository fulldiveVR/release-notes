- Interrupted model streams now recover with backoff, clearer failure handling, and improved event diagnostics.
- Fallback responses are sanitized to prevent invalid reasoning state from affecting later turns, while degraded upstream capacity is detected earlier to reduce unnecessary retries.
- Tenant action results are stored and delivered once per task, preventing duplicate results in A2A tasks.
- Browser assistance now handles continuation turns and adapter restarts more reliably, preserves browser state during idle shutdown, and keeps task status accurate while waiting for user input.
- Dynamic tool changes are carried into new runtime threads with relevant conversation context, improving continuity when available tools change.
- Storage and runtime lifecycle improvements reduce stale reads, bound temporary data growth, and increase resilience during restarts and concurrent workloads.
