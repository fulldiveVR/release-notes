summary: Improves scheduled automation, runtime reliability, resource monitoring, and recovery behavior across hosted workloads.
---

- Agents can create script-backed scheduled jobs, with improved handling for silent scheduled runs to reduce false incidents.
- Tenant reconciliation now uses each tenant’s current runtime lease, preventing stale or incorrect endpoint configuration after hibernation and wake-up.
- Trusted synchronization events use the Hub-configured model consistently, including during recovery.
- Codex runtime sessions release idle threads more reliably, preserve active background work, retry transient closing states, and expose loaded-thread health information.
- Workload monitoring now reports open-file usage and warns when a workload approaches its configured limit.
- Browser tab creation and interactive action recovery are more resilient when browsers are unavailable or an action completes without a valid UI payload.
