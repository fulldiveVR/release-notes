- Adds operational incident collection and report logs, with clearer filtering of superseded events and fewer duplicate failures after restart.
- Expands community marketplace support with tenant flavor publishing, trust-level visibility, publisher controls, lifecycle commands, and collection-level install and removal operations.
- Improves marketplace validation and installation reliability through stronger package checks, clearer conflict responses, bounded lock-file handling, and automatic runtime refresh after skill changes.
- Makes scheduled executions more predictable by preventing unintended schedule changes, allowing a run to manage its own schedule when appropriate, and improving compatibility with older runtime adapters.
- Makes signed file links persistent and improves delivery behavior for scheduled and asynchronous work, reducing unnecessary retries and stranded operations.
- Improves runtime lifecycle handling during pressure, eviction, restart, and access changes so active work is less likely to be interrupted and revoked access is applied after a safe restart.
