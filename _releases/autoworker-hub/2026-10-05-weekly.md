- Added operational incident collection and report logs to help operators investigate and track runtime issues.
- Expanded tenant marketplace support with community-trusted skills and flavors, publishing controls, install details, lifecycle commands, and clearer conflict responses.
- Improved scheduled runs with safer schedule-mutation rules, more reliable delivery, better prompt handling, and compatibility fallbacks for older adapters.
- A2A task updates now deliver descriptive progress steps in order, while recovery handles failed or interrupted work more reliably.
- Added standalone web-search forwarding and improved visibility for forwarded search requests.
- Improved persistence and reliability for signed file links, tenant provisioning, runtime recovery, and system service state checks.
