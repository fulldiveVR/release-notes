summary: This release adds catalog-driven interactive surfaces, scheduled action handlers, and improvements to runtime reliability, recovery, and database performance.
---

- Interactive surfaces now load their components from packaged skill catalogs, validate rendered content, support raw catalog messages, and handle user actions with updates to the existing surface.
- Schedules can run published action handlers instead of prompts, with configurable input and timeouts. Action executions recover across restarts and Hub upgrades without rerunning completed handlers.
- Detached background jobs keep tenants active until the work finishes, while scheduled jobs and silent service schedules are less likely to be reported as failures.
- Upstream runtime requests now retry selected transient failures before falling back, improving resilience to temporary connection, timeout, and service errors.
- Read-heavy database operations use a dedicated read pool, improving responsiveness under concurrent writes and reducing contention during busy periods.
