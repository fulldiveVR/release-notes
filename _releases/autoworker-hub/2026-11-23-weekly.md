---

- A2A runs now continue across turns until completion, while chat and Telegram runs retain their single-turn behavior.
- Continuation handling now preserves answers, removes status markers from user-visible output, and correctly handles cancellation, steering, adapter draining, and restored runs.
- Run activity timestamps are refreshed during continuation so stale-run cleanup reflects the latest progress.
- Administrators can set, update, or remove a per-tenant default model override.
- Browser service upgrades isolate tenant-level failures and preserve existing retired-browser payloads when needed for reliable restarts.
